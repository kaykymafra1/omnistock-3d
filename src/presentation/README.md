# Camada de apresentação

O componente visual é entregue consolidado em `dist/OmniWarehouse3D.html` para
manter compatibilidade com o Componente BI/HTML5 do Sankhya. A renderização 3D,
a árvore de locais e os modais pertencem a esta camada; regras de movimentação,
status e acesso aos dados ficam nas demais camadas.
